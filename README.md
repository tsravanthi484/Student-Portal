Project Overview

The Student Portal is a web-based application developed using React.js to provide students with an easy and organized way to access courses and manage their basic student information.

The application contains multiple pages such as Home, Courses, Course Details, Login, and Dashboard. Students can browse different courses, view detailed course information, log in to their account, and access their dashboard.

The project uses React Router for smooth navigation between pages and Local Storage to maintain the student's login status. Course information is maintained separately and displayed dynamically based on the selected course.

Key Features
🏠 Home Page – Introduction to the Student Portal.
📚 Courses – Displays available courses like React, JavaScript, Python, and Java.
📖 Course Details – Shows course ID, duration, description, and topics.
🔐 Login – Provides student login functionality.
📊 Dashboard – Displays student overview and progress information.
👤 Profile – Shows student personal and academic details.
⚙️ Settings – Provides notification and reminder settings.
🚪 Logout – Allows students to securely leave the dashboard.
📱 Responsive UI – Designed to work on different screen sizes.
